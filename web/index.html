💡 怎么看

红色 = 涨 / 强,绿色 = 跌 / 弱
上涨中 = 现价 > 1月线 > 3月线 / 下跌中 = 现价 < 1月线 < 3月线
反弹中 = 短期回升、中期未确认 / 回调中 = 中期仍涨、短期回落
V 估值分: +2 = 相对自身历史偏便宜,-2 = 相对自身历史偏贵；红利低波看自身PE分位(股息率作背景),沪深300看PE/PB/股债利差,其他指数看自身PE分位,黄金看年线位置
T 趋势分: +2 = 上涨趋势,-2 = 下跌趋势
M 动能分: +2 = 短期上涨有延续,-2 = 下跌动能较强；过热/超跌另作风险提示
中长期趋势: 看160/200/240日是否多数同向；60日波动越高,过程可能越颠簸
S 总分: 仅在 V/T/M 都有数据时计算；正数偏强,负数偏弱,只作双轮解释
基本面: 五维评分(ROE/成长/负债/估值/毛利)+ 12个月估值区间,数据每日云端更新
选择历史日期时,无历史估值的数据会把 V/S 显示为 —,不会拿今天的估值冒充历史值
标有“观察”的指数尚未纳入三资产策略回测,但仍按同一套规则输出当前结果；标签只提示回测成熟度

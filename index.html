💡 怎么看

红色 = 涨 / 强,绿色 = 跌 / 弱
上涨中 = 现价 > 1月线 > 3月线 / 下跌中 = 现价 < 1月线 < 3月线
反弹中 = 短期回升、中期未确认 / 回调中 = 中期仍涨、短期回落
V 估值分: +2 = 便宜,-2 = 贵(黄金按年线乖离;其他指数见每日邮件)
T 趋势分: +2 = 上涨趋势,-2 = 下跌趋势
M 动能分: +2 = 短期强势,-2 = 弱势,涨太猛会扣分
S 总分: V+T+M,正数偏强,负数偏弱
基本面: 五维评分(ROE/成长/负债/估值/毛利)+ 目标价,数据每日云端更新,港股暂缺
选择日期可查看该日收盘后的信号(最早约3年前)
估值(PE/PB/股息率)和详细理由见每日邮件
